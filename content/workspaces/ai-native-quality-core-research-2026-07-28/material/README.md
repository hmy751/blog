# Material

이 디렉토리는 최종 원칙보다 앞선 재료를 보존한다.

- 사용자의 의도와 품질 신호
- 실제로 관찰된 실패 장면
- 서로 경쟁하는 원인 가설
- Current, 기존 다섯 후보, Alex, 다른 AI-native 작업의 대조

이곳의 가설은 현재 결론이 아니다. 서로 충돌하거나 일부만 설명하는 가설도 수거 전까지 남긴다.
