# Candidates

이 디렉토리는 최종 core에 넣을 최소 목록이 아니라, 검토할 수 있는 후보 공간을 만든다.

- 비슷한 후보도 작동 위치나 실패 방식이 다르면 따로 남긴다.
- 각 후보는 정의뿐 아니라 근거, 발동 신호, 실제 행동, 대비 사례, 비적용 조건, 전이 가능성, 근거 한계를 함께 본다.
- 후보 수를 미리 제한하지 않는다.
- 합치기, 승격, 보류, 탈락은 `synthesis/`에서 나중에 다룬다.
