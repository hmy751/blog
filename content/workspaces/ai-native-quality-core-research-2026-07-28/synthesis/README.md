# Synthesis

이 디렉토리는 충분히 펼친 material과 candidates를 나중에 수거하는 곳이다.

현재는 필터 단계가 아니다.

수거할 때도 다음을 구분한다.

- 여러 사례에서 반복되고 사용자와 거의 합의된 것
- 일반화 가능성이 있지만 다른 사례 대조가 더 필요한 것
- Current 또는 글쓰기에 묶인 적용 사례
- Alex 원본이 지원하지 않는 확대 해석
- 사용자 판단이 필요한 목적·권한·학습 형식
- 근거 부족으로 보류할 것

종합문을 만들더라도 원재료 문서를 대체하거나 삭제하지 않는다.
