# Active State

이 문서는 이 workspace의 전체 그림과 현재 판단점을 낮은 해상도로 보여 주는 재진입 지도다. 현재 단계만 요약하지 않고, 왜 시작했는지, 무엇을 펼쳤는지, 무엇이 어색하다고 판정됐는지, 다음에 무엇을 판단할지를 한 화면에 둔다.

상세 근거와 후보를 모두 여기로 옮기지 않는다. 직접 원천은 `sources`, 관찰과 원인 가설은 `material`, 넓게 펼친 패턴은 `candidates`, 현재 수렴 산출물은 `src`, 전체 확장 지도와 수렴 방식은 `synthesis`가 소유한다. 과도하게 원자화한 첫 확장과 구현 형식 카탈로그는 서로 다른 reference로 `references/`에 보존한다.

## 현재 목표

> 사용자 의도와 실제 실패 장면을 source에서 복구하고, 공식 문서와 기존 하네스가 제공하는 서로 다른 작동 형식을 비교해, 다른 AI-native 작업에서도 성과를 낼 가능성이 있는 완결된 후보를 만든다. 후보가 실제 판단과 결과를 어떻게 바꾸는지 사례로 확인한 뒤에만 적절한 하네스 위치를 정한다.

이 workspace의 목표는 `core`, skill, agent, workflow 같은 특정 형식을 채우는 것이 아니다. 여기서 `성과`는 같은 문제에서 더 나은 판단 또는 결과를 만들거나, 반복 실패를 더 일찍 발견하거나, 다음 작업에서 유효한 판단을 다시 사용할 수 있게 되는 변화다.

## 유지 원칙

- 이 문서에는 진행 cursor를 하나만 둔다.
- 완료된 큰 가지도 현재 판단을 이해하는 데 필요하면 접어서 남긴다.
- 사용자와 합의되지 않은 일반화는 현재 원칙처럼 쓰지 않고 `[열림]` 또는 `[보류]`로 표시한다.
- 상세 문서를 열지 않아도 현재 위치와 다음 판단을 알 수 있게 하되, 후보 전체를 이 문서에 복제하지 않는다.
- 형식 카탈로그가 내용의 중요도와 채택을 결정하지 않는다.

## 현재 지도

- 작업의 목적
  - Current 글 한 편의 복구 절차나 `core` 문서 완성이 아니라, AI-native 작업에서 결과와 그 결과를 만든 판단 체계를 함께 개선할 실제 작동 방식을 찾는다.
  - 문제 해결뿐 아니라 사용자가 나중에 다시 읽고 자신의 판단과 역량을 복원할 수 있는 설명·대비·사례를 남긴다.
  - 글쓰기 사례를 보존하되 일반 AI-native 문제 해결이 우선이다.
  - 유효성이 확인된 뒤에만 적절한 하네스 형식과 owner를 정한다.

- 출발한 품질 문제
  - Material과 동기는 있었지만 완결 결과와 review에서 반복해서 사라졌다.
  - A/B는 서로 다른 문장을 만들었지만 Q1~Q5와 최근 장면이 대표 문제라는 같은 frame을 공유했다.
  - 결과를 같은 goal·criteria·review 체계 안에서 계속 고쳐, 완성도는 올라가도 frame 자체의 품질은 다시 보지 못했다.
  - 사용자의 목적, 작업 가설, reviewer 제안, 현재 합의의 권위가 작업 중 섞였다.
  - 직접 장면과 대화 계보는 [원본 workspace](../ai-native-topic-research-2026-07-20/active-state/index.md), [사용자 의도와 품질 신호](./material/01-user-intent-and-quality-signals.md), [관찰된 실패 장면](./material/02-observed-failure-scenes.md)이 소유한다.

## 현재 거의 합의된 방향

- 완결된 결과를 만드는 것과 결과를 만든 판단을 별도 위치에서 다시 보는 것은 양립한다.
- 완결 결과는 최종 답이면서 현재 goal·context·constraint·evaluation 체계가 만든 관찰물이다.
- 결과가 약할 때 모든 단계를 다시 감사하지 않고, 한 번 종합 판정한 뒤 실제로 문제를 만든 책임만 다시 연다.
- 같은 frame 안의 완성도와 frame 자체의 품질을 분리한다.
- source가 존재하거나 AI가 읽은 것과, source가 결과의 동기·중심·판단에 실제로 작동한 것을 구분한다.
- 여러 reviewer와 분석은 각자 다음 단계를 결정하지 않고 main이 회수한다.
- Alex의 표면 workflow를 복제하지 않고, 확인된 행동과 우리의 해석을 분리한다.
