# Current Working Outputs

이 디렉토리는 과거의 84개 요소 확장 기록이 아니다. 사용자 의도와 실제 실패 장면에서 문제를 다시 수거하고, 문제 사이의 관계와 우선순위를 판단한 뒤, 실제 차이를 낼 후보를 만드는 현재 작업면이다.

- [84개 하네스 요소 계약으로 원자화한 첫 확장 기록](../references/atomic-element-expansion/)
