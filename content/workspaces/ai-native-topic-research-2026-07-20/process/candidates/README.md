# Candidates — 후보를 만들고 다시 판단한 과정

이 디렉토리는 글감 후보를 발견하고, 판단 기준을 만들고, 원천에서 다시 조사하고, 후보 관계와 위상을 교정한 과정을 보여 준다.

현재 유효한 후보 목록을 직접 소유하지 않는다. 현재 기준과 후보 상태는 [active-state](../../active-state/index.md)에서 확인한다.

## 문서

### [01-criteria-and-decision-history.md](./01-criteria-and-decision-history.md)

후보를 고르는 기준이 어떤 정정과 사례를 거치며 만들어졌는지 보여 준다.

### [02-topic-candidates.md](./02-topic-candidates.md)

원천 우선 재조사 전에 형성된 다섯 후보를 같은 해상도로 펼친 snapshot이다.

### [03-source-first-reanalysis.md](./03-source-first-reanalysis.md)

기존 후보를 직접 고쳐 쓰지 않고 원자료에서 판단 사건과 fresh 후보를 다시 추출해 대조한 과정이다.

### [04-post-03-candidate-state-correction.md](./04-post-03-candidate-state-correction.md)

재조사 결과를 후보 위상으로 옮기는 과정에서 생긴 오독과 사용자 교정, 후보 관계 재판정을 보여 준다.

## 읽는 순서

후보가 만들어지고 달라진 순서를 보려면 `01 → 02 → 03 → 04`로 읽는다. 당시 상세 후보 카드에서 근거를 추적하려면 [이전 topic-candidates](../context-structure/legacy-active-state/topic-candidates.md)에서 연결된 문서로 바로 내려간다. 현재 그림은 [active-state](../../active-state/index.md)를 따른다.

이 네 문서는 과거 이력만 모은 archive가 아니다. 후보를 만들고 재검토할 때 실제로 수행한 서로 다른 종류의 작업을 보존한 과정 문서다.
