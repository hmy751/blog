# Current scaffolding rewrite

이 cycle은 `current`를 과거 기록과 현재 계약의 권위 분리 사례로만 읽지 않고, 전체 프로젝트의 낮은 해상도 지도와 단일 cursor를 함께 보여 주어 세션 사이 재진입과 sync를 돕는 scaffolding으로 다시 세우려 한 부분 재작성 과정이다.

현재 의미와 중심은 [Current 글 active-state](../../../active-state/current-active-state-operation.md), 전체 위치는 [active-state index](../../../active-state/index.md), 반복 판단축과 반영 권한은 [core](../../../core/workflow.md), 사실은 [sources](../../../sources/index.md)가 가리키는 직접 원천이 우선한다. 이 디렉터리의 기록과 review는 이번 편집 과정을 복구하는 process이며 현재 판단이나 사실의 권위가 아니다.

작성 당시 shaping·evidence·texture 검토와 원고만 본 추가 판별은 통과 또는 `light edit`을 보고했다. 이후 사용자는 원고에 `current`를 둔 이유, 해커톤 전체 맥락, 글쓴이의 근거·논리·판단이 빠졌다고 판정했다. 따라서 이 cycle은 완료·수용된 Current가 아니라, review 입력과 개선 기준 계약의 부족을 드러낸 작업 시도로 남긴다.

## 이번 cycle의 경계

- Current 한 편만 수정한다.
- 다른 네 원고, active-state, core, sources, 기존 process 기록은 수정하지 않는다.
- 공개 발행 후보로 승격하지 않으며 `date: TBD`를 유지한다.
- 첫 답변의 보존되지 않은 문구를 재구성하지 않고, 직접 기록이 지원하는 시간축과 근거 배치만 비교한다.
- 다음 수정은 이 cycle의 완료 판정을 전제로 하지 않고, 현재 작업본과 직접 원천을 함께 보는 개선 review의 기준 후보부터 다시 확인한다.
