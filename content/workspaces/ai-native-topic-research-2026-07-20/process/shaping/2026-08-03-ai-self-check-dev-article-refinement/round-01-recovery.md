# Round 1 — Main 회수

[round-01-review.md](./round-01-review.md)의 report를 Material → Shaping → Texture → Reader Flow 순으로 회수했다. 전체 판정은 고우선 blocker 없음(발행 전 해소 조건 1건은 아래에서 닫음).

## 수렴 표시

핑퐁 반례 문단을 섹션 4 도입으로 옮기는 제안은, standalone review 수신 전에 고정한 main의 사전 판단(중반 하중, 반례의 역할 애매·이동 후보)과 이번 fresh reviewer가 서로 다른 입력 경계에서 독립적으로 닿은 수렴 지점이다. 우선 처리 후보로 사용자에게 올렸고 수용됐다.

## 바로 적용 (표현·사실 정리, main 권한)

1. [P1] 해커톤 진입 문단 정비 — 주술 어긋남(`자료는 ... 비중을 뒀습니다`)을 `저는 ... 비중을 두고 ... 찾았습니다`로 바로잡고 전환 구절을 정리했다. reviewer 대체 문안 채택.
2. [P2] 사용자 정정 순서 보강 — `제가 이전 합의와 더 넓은 대화를 다시 보라고 정정한 뒤, 두 번째 self-check가 이 축소를 찾았습니다.` packet의 순서 기록과 일치를 확인하고 반영.
3. [P2] `여기서 세 결과가` → `여기서 세 가지가` (지시 대상 정합).
4. [P3] `감사 초점` → `점검 초점` (글에서 한 번만 나오는 고아 용어 정리).
5. [P3] 6월 12일 원문 근접 문구 소화 — `불완전한 여행 자료와 애매한 사용자 질문` → `빈 곳이 많은 여행 자료와 뜻이 분명하지 않은 사용자 질문`.

## 기각

- [P3] `핑퐁` 라벨 제거 제안 — 저자 어휘와 질감 보존으로 기각. 바로 앞 문장이 뜻을 풀어 주고 있어 라벨 유지가 낫다고 판단했다.

## 사용자 결정과 반영

구조화 질문 패널은 먼저 닫혔고, 평문 재설명 뒤 받은 답변 원문:

> "2번 먼소린지 모르겠고 기억 안나 / 3번 기억 안나 / 나머지 뭐 오케이"

1. 핑퐁 반례 문단 이동(섹션 3 끝 → 섹션 4 도입): 수용 → 반영. 섹션 3은 `각각 다음 판단에 쓰이는 재료였습니다`로 닫히고, 섹션 4가 판단이 돌아오는 반례로 열린다.
2. 다섯 위치 시점 프레이밍: 당시부터 다섯 이름으로 봤다는 기억 없음 → `지금 정리하면 보던 위치는 다섯입니다`로 반영. 원고 자신의 소급 금지 태도, packet의 빈 기억 절과 일치한다.
3. 결말 실행 절차 리스트화: 판단 유보(해당 부분에 대한 기억·감각 없음) → 산문 유지. 열린 결정으로 남겨 round 2 판정이나 최종 재독에서 다시 본다.
4. 아카이브 미니 대조 장치: main 권고(다섯 위치 리스트 직후라 장치 과밀 위험)대로 이번 회차에는 넣지 않음. 사용자 수용.

## Source 쟁점 해소

1. 비호출 장면 원천 미등재(reviewer의 유일한 발행 전 해소 조건) — main이 직접 탐색해 해소했다. 마이리얼트립 조사 기록 09 파일 61~65행에서 장면 전체(방향 정정으로 오독, `아냐 그냥 물어본거야`, 점검 중단, `조사 방법만 고정` 설명)를 확인했고 [source packet](../../../sources/ai-self-check-origin-and-operation.md)에 등재했다. standalone review 때부터 세 번 연속 지적된 지점이 닫혔다.
2. 다섯 위치 프레임 시점 — 위 사용자 결정 2로 해소.
