# AI self-check 최종 evidence report

## 입력과 역할

생성 계보와 직접 원천을 앞서 조사한 report-only 주체가 `round-05-draft.md`만 새로 읽고, 날짜·행위 주체·인과·수치·AX 도식·최초 inline과 후대 fresh 구분·현재 회고의 시간 경계를 대조했다. 이전 draft·review·writer brief·process는 입력에서 제외했다.

## Claim별 판정

### 한 과제 원본 발견 뒤 세 곳 추가 분류 — Supported / Bounded

- TVING을 다시 확인한 뒤 전체 과제를 같은 조건으로 보고 세 곳을 더 고친 순서와 `3곳 추가` 수치는 2026-05-21 원본 rollout에 있다.
- `원본 이미지`는 파일 형식까지 복원되는 표현보다 한 단계 강하다. `재구성의 바탕으로 볼 수 있는 원본 자료`가 안전한 상한이다.

### 최초 self-check의 inline 계약 — Bounded

- 5월 기록은 `ai-self-check`와 별도 `principle-calibration-auditor`를 구분하며 self-check 전용 auditor 생성은 기록하지 않는다. 최초 self-check가 같은 AI의 판단을 다시 보는 규칙이었다는 계보와 맞는다.
- 7월 6일 최초 Git snapshot에는 이미 fresh auditor가 있다. 5월 구현 파일을 직접 확인한 사실보다 강하게 확대하지 않는다.

### 6월 5일 진단과 직후 제안 — Supported

- AI가 불확실성을 통제하기 쉬운 데모로 바꾸려 했다고 정확히 진단한 뒤, 같은 답에서 deterministic baseline·extractor·상태 흐름을 길게 제안했다.
- 사용자는 구현 수단보다 그 방향 자체가 핵심이라고 다시 좁혔다.
- `진단 품질 / 직후 행동 변화 / 재발 감소`를 다른 결과로 보는 원고의 구분과 충돌하지 않는다.

### 6월 중순 fresh 실사용과 최초 여부 — Supported / Bounded

- 6월 12일에는 사용자가 self-check를 직접 호출했고 fresh auditor가 Main의 좁아진 문제 정의를 다시 연 실제 사용이 확인된다.
- `최초 전환인지는 확인되지 않는다`는 원고의 한계가 정확하다.
- pipeline·label 축소와 동적 상황 해석 회수는 source card에 보존되지만 parent 대화·tool invocation 전문이 모두 남은 것은 아니다.

### AX 회사 자료 전제·독립 경로·복구 — Supported / Conflict

- 회사 공식 자료는 회사 방향을 볼 때 높은 가중치를 유지했고, 사용자·외부 자료는 현재 남은 문제를 확인하는 역할이었다.
- 첫 self-check가 회사 자료 가중치 자체는 나쁜 편향이 아니라고 판정한 사실, Main이 적용하며 기존 합의를 잃은 사실, 두 번째 self-check와 사용자 정정으로 두 증명 범위와 다음 조사 질문을 복구한 사실은 지원된다.
- `사용자 문제 삭제`는 너무 강하다. 사용자 문제 확인은 회사 방향 주변의 미해결 마찰 확인으로 남았고, 사라진 것은 회사 방향과 나란히 독립적으로 펼쳐 접점에서 질문을 고르던 경로다.

### 7월 forward 반례 — Supported

- `일단 전진` 기본값을 고치는 대화에서 AI가 다시 초안·실행으로 서둘렀고 사용자가 생각과 전후 차이를 먼저 보여 달라고 여러 차례 제동했다.
- `앞선 이해에 쌓이지 않는 핑퐁`은 현재 저자의 해석이며 과거 사실로 잘못 소급하지 않았다.

### input pull 전환 — Conflict / Supported

- 기존 7월 6일 계약도 최근 교환 원문을 verbatim으로 전달하고 요약·해설하지 않게 했다. `원인을 요약해 넘겼다`는 서술은 맞지 않는다.
- 실제 문제는 Main이 감사 초점과 필요한 과거 원문 범위를 먼저 정해 사건을 구성한 일이었다.
- 7월 14일에는 발동 발화와 직전 교환을 seed로 주고 필요한 과거 범위를 auditor가 직접 pull하도록 바뀌었다.

### 호출 문턱 — Supported

- 단순 기준 확인 질문을 Main이 self-check 신호로 읽었다가 사용자가 그냥 물어본 것이라고 하자 평범한 설명으로 돌아간 장면이 있다.
- 7월 20일에는 첫 이해 실패·첫 정정은 Main이 직접 고치고, 같은 판단축이 반복되거나 별도 판단을 명시할 때 fresh auditor를 부르도록 좁혔다.

### 분석 문서 사례 — Supported

- Main은 넓은 맥락 누수로 정의했고 auditor는 문서가 자기 객관성을 본문에서 변호하려는 문제로 더 좁혔다.
- 후속 설명이 길고 어려워 사용자가 다시 정정했다.
- auditor 관점이 좋았다는 평가는 현재 저자의 1인칭 판단으로 남아 있다.

### 현재 회고의 시간 경계 — Supported

- `여러 번 사용한 뒤 이 글을 쓰는 지금` 생긴 이해와 5월 최초 설계 의도를 명시적으로 분리한다.
- 사용자의 기준도 대화 중 선명해질 수 있다는 이해를 5월 의도로 소급하지 않는다.

## 공개 경계

- 로컬 절대경로, session ID, 비공개 코드, 회사명, 개인 평가 원문은 공개 원고에 노출되지 않았다.
- private 대화의 표현인 `불확실성을 통제 가능한 데모로 바꾸려는 충동`, `맥락 누수`는 원문 인용처럼 쓰지 않고 저자 문장으로 풀어야 한다.

## P0 / P1

- P0: 없음.
- P1:
  1. AX 도식의 `사용자 문제 삭제`를 `독립 경로가 회사 방향 주변 마찰 확인에 종속됨`으로 고친다.
  2. `원인을 요약해 넘기면`을 `Main이 감사 초점과 원문 범위를 먼저 골라 넘기면`으로 고친다.
  3. private raw의 두 표현을 직접 인용하지 않고 공개 가능한 저자 문장으로 다시 쓴다.

## 안전한 최소 정정

- `한 과제에서 재구성의 바탕으로 볼 수 있는 원본 자료가 나왔다.`
- `회사 방향과 나란히 보던 사용자 문제의 독립 경로를 회사 방향 주변의 마찰 확인으로 축소했다.`
- 도식의 `사용자 문제 → 삭제`를 `사용자 문제 → 독립 경로를 잃고 위 흐름에 종속`으로 바꾼다.
- `주 작업 AI가 감사 초점과 관련 원문 범위를 먼저 골라 넘기면, 별도 AI는 이미 Main이 구성한 사건을 보게 된다.`
- private 표현은 `불확실성을 검증하기 쉬운 데모로 바꾸려 했다`, `결과와 직접 관계없는 제작 과정의 정당화가 본문에 섞인 문제로 좁혔다`로 풀어쓴다.

## 정정과 regression

Main은 위 판정에 따라 최종 후보를 국소 수정했다.

- 원본의 파일 형식을 단정하지 않고 `재구성의 바탕으로 볼 수 있는 원본 자료`로 낮췄다.
- AX의 `사용자 문제 삭제`를 독립 경로의 축소와 종속, 뒤이은 복구로 고쳤다.
- input pull의 문제를 요약 전달이 아니라 Main이 감사 초점과 원문 범위를 먼저 정한 일로 바로잡았다.
- private raw의 데모 표현과 분석 문서 표현을 직접 인용하지 않고 공개 가능한 저자 문장으로 풀었다.

같은 evidence checker가 바뀐 구간만 다시 대조했다. 첫 regression에서 `지워진 입력 범위`라는 과장과 private auditor 문장에 가까운 표현 두 곳을 추가로 찾았고, Main은 각각 `축소됐던 입력 범위`, `결과와 직접 관계없는 제작 과정의 정당화가 본문에 섞인 문제`로 고쳤다. 두 번째 국소 regression 결과 P0와 P1은 남지 않았다.

최종 판정: **Evidence pass**

## Round 05 fresh review 회수 뒤 regression

완료 감사에서 새 fresh reviewer의 전체 판정을 회수한 뒤 현재 src의 네 구간이 추가로 달라졌다. 같은 evidence checker가 직접 원천 기준으로 그 구간만 다시 확인했다.

- 진단 정확도·직후 제안 변화·재발 감소를 세 질문으로 풀어쓴 문장은 6월 5일 사건의 구분과 맞는다.
- `남은 기록에서는 6월 중순에`라는 fresh 장면 전환은 확인 가능한 실사용 범위 안이며 최초 여부를 확정하지 않는다.
- H3 제거는 사실·인과를 바꾸지 않는다.
- 결말의 작동형 문장은 과거 효과 주장이 아니라 현재 독자가 실행할 점검이며, 다섯 위치와 다음 동작 예시는 본문 사건에 근거한다.

새 공개 경계 누수도 없다. 최종 회수본의 P0와 P1은 **없음**이다.
