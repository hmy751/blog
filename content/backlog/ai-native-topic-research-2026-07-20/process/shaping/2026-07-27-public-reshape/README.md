# Public reshape cycle

이 묶음은 `near-final v3`를 문장 단위로 polish하는 작업이 아니다. 사용자가 다섯 v3를 블로그 글로 읽었을 때 매력과 풍부함이 부족하고, 특히 익명화된 내부 보고서처럼 시작하는 문제가 있다고 판단한 뒤 공개 독자 기준으로 구조를 다시 잡는 작업이다.

기존 `near-final-v2`와 `near-final-v3`, 그 review와 검증 기록은 당시 판단을 복구할 수 있는 snapshot으로 그대로 보존했다. 새 원고는 기존 파일을 덮어쓰거나 `v4`로 잇지 않고 다음 위치에 완결된 새 cycle의 v1로 만들었다.
